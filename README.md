# Clara Odontologia Integrada

Landing page responsiva demonstrativa para uma clínica odontológica, feita com Next.js 15, React e CSS.

## Rodar localmente

```bash
npm install
npm run dev
```

## Antes de publicar

O conteúdo é uma demonstração visual. Atualize endereço, telefone/WhatsApp, redes sociais, registro profissional, depoimento, avaliações e quaisquer alegações sobre a clínica em `app/page.tsx`. Substitua também as fotografias Unsplash por imagens autorizadas da clínica. Não publique dados ilustrativos como se fossem informações reais.

## Verificações

```bash
npm run lint
npx tsc --noEmit
npm run build
```

O build e a checagem de tipos também foram verificados em Termux/Android usando a distribuição WebAssembly do SWC.
